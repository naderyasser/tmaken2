# دليل تعديل ومشاهدة بيانات الموظفين

## ✅ التحديثات المضافة

تم تحديث النظام لإضافة القدرة على **تعديل ومشاهدة معلومات الموظفين** بالكامل.

---

## 🚀 كيفية الاستخدام

### 1️⃣ عرض قائمة الموظفين
- اذهب إلى: `/employees`
- ستشاهد قائمة بجميع الموظفين مع إمكانية البحث والفلترة

### 2️⃣ مشاهدة وتعديل موظف
- اضغط على أي موظف في القائمة
- أو اضغط على أيقونة "تعديل" (✏️) من قائمة الإجراءات
- سيتم فتح صفحة تعديل الموظف: `/employee/{employee_id}`

### 3️⃣ إضافة موظف جديد
- اضغط على زر "إضافة موظف" 
- سيتم فتح صفحة إضافة موظف جديد: `/employee/new`

## 🔗 API Endpoints المستخدمة

جميع الـ endpoints موجودة في `/lib/api-client.ts`:

### 1. جلب قائمة الموظفين
```typescript
frappeClient.getEmployees(options)
// GET /api/resource/Employee
```

### 2. جلب موظف واحد
```typescript
frappeClient.getEmployee(employeeId)
// GET /api/resource/Employee/{employeeId}
```

### 3. تحديث بيانات موظف
```typescript
frappeClient.updateEmployee(employeeId, updates)
// PUT /api/resource/Employee/{employeeId}
```

### 4. إضافة موظف جديد
```typescript
frappeClient.createEmployee(employeeData)
// POST /api/resource/Employee
```

### 5. حذف موظف
```typescript
frappeClient.deleteEmployee(employeeId)
// DELETE /api/resource/Employee/{employeeId}
```

## 🎯 البيانات المتاحة للتعديل

### المعلومات الشخصية
- `employee_name` - اسم الموظف
- `employee_number` - رقم الموظف
- `cell_number` - رقم الهاتف
- `company_email` - البريد الإلكتروني (العمل)
- `personal_email` - البريد الإلكتروني (الشخصي)
- `date_of_birth` - تاريخ الميلاد
- `gender` - الجنس (ذكر/أنثى)
- `status` - الحالة (نشط/غير نشط/مغادر)

### تفاصيل العمل
- `department` - القسم
- `designation` - المسمى الوظيفي
- `date_of_joining` - تاريخ الالتحاق

## 🧪 كيفية الاختبار

### 1. تشغيل المشروع
```bash
npm run dev
# أو
pnpm dev
```

### 2. فتح صفحة الموظفين
```
http://localhost:3000/employees
```

### 3. اختبار التعديل
1. اضغط على أي موظف من القائمة
2. عدل البيانات (مثل: الاسم، الهاتف، القسم)
3. اضغط "حفظ التغييرات"
4. ستظهر رسالة نجاح وسيعود للقائمة

### 4. اختبار الإضافة
1. اضغط "إضافة موظف"
2. املأ البيانات المطلوبة
3. اضغط "حفظ التغييرات"
4. ستظهر رسالة نجاح
